Token Radar ranks 198 pre-token protocols by implied value, computed from a sealed snapshot with one stated formula for every row: TVL × a category-calibrated market-cap-to-TVL ratio × growth and maturity multipliers, with no protocol name special-cased. Each row carries a six-step farm plan with cost and time estimates. The dashboard is a sortable, filterable board with search, category and chain filters, a detail view per protocol, and live self-checks that recompute every value from the same formula.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
